# Approved art exports

This directory includes the approved PNG/model exports needed for deterministic resource rebuilding. PNG exports are directly editable pixel assets. Local drafts, editor history, prompts, previews and machine-specific helper scripts are excluded.

The installer uses biology_items_v05, functional_faces_v01, cultivation_chamber_v02, array_faces_32_v06, basic_planter_v05, cell_cultivator_v06, me_infusion_altar_v05 and controller_animation_v01 under drafts/. Runtime resources are committed in src/main/resources; ordinary builds do not need art tools.

Keep third-party notices and licenses when redistributing assets. No personal image metadata is required for building or editing these exports.
