# Source snapshot scope

This update is based on the existing public repository history. Private development commits are not ancestors of this snapshot. The snapshot contains runtime sources/resources, tests, build files, licenses and required art exports.

Personal paths, launcher files, game instances, prompts, editor history, rejected experiments, backups and local logs are excluded. The installed asset graph and release JAR are audited separately; hidden seed-storage compatibility IDs are deliberately retained for old saves.
