# Source snapshot scope

This first implementation snapshot contains runtime source/resources, tests, Gradle Wrapper/build files, required art exports and licenses. It is based on the existing public repository history; private development-history commits are not ancestors of this snapshot.

Local editor histories, personal paths, prompts, game instances, archives, logs and backups are excluded. PNG exports have non-image text, EXIF and timestamp metadata removed without changing image/color/animation chunks. Upstream license and copyright notices remain in the repository.
