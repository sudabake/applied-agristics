# ME Infusion Altar

<BlockImage id="appliedagristics:me_infusion_altar" scale="5" />

The ME Infusion Altar runs Mystical Agriculture infusion recipes, including orders from an ME network.

## Set up the altar

Replace the middle altar of a Mystical Agriculture setup with the ME Infusion Altar. Keep the eight infusion pedestals around it. For auto-crafting, use a processing pattern and put a Pattern Provider next to the ME altar.

## Output and upgrades

- ME crafting orders return the result to the network.
- With manual inputs, use the side toolbar to send finished items to neighbouring inventories. All faces can receive valid input.
- The altar accepts up to four <ItemLink id="ae2:speed_card" /> upgrades.
