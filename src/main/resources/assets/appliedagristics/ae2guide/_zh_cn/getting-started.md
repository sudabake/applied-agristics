# 基础种植机

<BlockImage id="appliedagristics:early_planter" scale="5" />

基础种植机一次种一种作物，前期有种子和耕地就能用。

## 开始种植

1. 把种子和对应的耕地放进两个输入槽。
2. 想加快收获就给机器加水。水箱空了仍会继续种植。
3. 从右边的槽取走产物，也可以从底部接管道抽取。

部分作物需要特殊耕地或基座，具体要求会显示在界面上。输出槽满时，机器会保留已经完成的一批产物，腾出空间后再输出。
