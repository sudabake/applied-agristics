# Basic Planter

<BlockImage id="appliedagristics:early_planter" scale="5" />

The Basic Planter grows one crop at a time. It works before you have an ME network.

## Start a crop

1. Put the seed and compatible farmland in the two input slots.
2. Give the machine water if you want faster harvests. It keeps growing when the tank is empty.
3. Take the harvest from the right-hand slots. You can extract it from the bottom with a pipe.

If a crop needs a special block or soil, check the requirements shown on screen. If the output is full, the planter holds its completed harvest until there is room.

## Next step

Use the Basic Planter to craft the <ItemLink id="appliedagristics:network_planter" />. JEI shows recipes and the possible harvests for each crop.
