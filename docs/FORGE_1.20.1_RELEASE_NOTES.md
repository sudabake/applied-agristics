# Applied Agristics 1.3.2 for Forge

应用农业 1.3.2 的首个 Minecraft 1.20.1 Forge 测试版。

- 延续 1.3.2 的农业阵列、生物培养器、ME 注魔祭坛、界面和材质。
- 保留 JEI 种植产物、加工样板、可拖动的多方块预览和 GuideME 指南。
- 使用 Project Infinity 猪咪版 1.1.1 副本完成启动验证，并分项验证 JDTE 温室、EAEP 派单和 Cell4＋NeoEcoAE 库存显示。

运行环境为 Minecraft 1.20.1、Forge 47.4.20 和 Java 17。前置为 AE2 15.4.10 与神秘农业 7.0.24，它们分别使用 GuideME 20.1.15 和 Cucumber 7.0.16。请为两个 Minecraft 版本分别使用对应存档。

This is the first Forge beta of Applied Agristics 1.3.2 for Minecraft 1.20.1. It brings over agricultural arrays, the ME Biological Cultivator, the ME Infusion Altar, JEI previews and processing patterns, and the AE guide pages. Tested with Forge 47.4.20, Java 17, AE2 15.4.10, Mystical Agriculture 7.0.24, GuideME 20.1.15 and Cucumber 7.0.16. Use a separate save for each Minecraft version.
