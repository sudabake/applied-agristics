# Applied Agristics 1.3.1

## 中文

- 内置原版树苗、杜鹃和下界巨型菌种植规则，无需安装 Botany Pots。统一生产周期与掉落，可通过数据包调整。
- 多方块成型、拆除和重新成型保留部件朝向，成型后端口仍可用扳手旋转。
- 修正树木与特殊植物的配方优先级，完善甘蔗、仙人掌、竹子、海带、浆果与蘑菇的种植支持。
- 实际耗电与升级预估统一使用批次限制，改善 JEI 种植产物预览和外部配方输入枚举。
- planting 配方支持可选 loot_table 字段。
- 客户端与服务器需同时更新。旧版本已被自动改变的朝向需要手动调整一次。

## English

- Add native planting rules for vanilla saplings, azaleas and huge fungi without requiring Botany Pots, with data-pack configurable cycles and drops.
- Preserve part facing when forming or breaking an array, and allow formed ports to rotate with a wrench.
- Fix recipe priority for trees and special plants, and improve native fallback planting support.
- Align energy estimates with actual batch limits and improve JEI planting previews and external recipe inputs.
- Support the optional loot_table field in planting recipes.
- Update both client and server. Previously overwritten part orientations must be adjusted manually once.
