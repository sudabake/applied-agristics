# Applied Agristics beta1.1

Minecraft 1.21.1 · NeoForge 21.1.248 · Java 21

仍处于测试和平衡阶段。客户端与服务端请一起更新。

- 作物仓接收阵列全部收获物；新生种子优先进入同阵列 ME 种子仓。移除控制器直入 ME 设置，保留输出口自动输出。
- 普通种子仓取出使用中的种子会暂停对应作物；基础种植站快捷放入种子不再堆进输出槽。扳手旋转与拆卸加入音效。
- 背包与 JEI 悬停显示用途，按住 Shift 查看详情；G 接入 AE2 共享指南，U／G 结构预览支持拖动旋转。
- 收窄普通作物筛选按钮并与下方按钮组对齐；更新用户手绘生物棉签、项目图标及成品资源组织。

Crop Storage now accepts all array harvests. New seeds go directly to the same array's ME Seed Storage. Inventory interactions, tooltips and the shared AE2 guide have been improved. Structure previews support drag rotation. Includes updated swab artwork, project icon and package cleanup.

This is a testing and balancing version. Update both client and server.

Required: AE2 19.2.17+, Mystical Agriculture 8.0.27+, Cucumber 8.0.16+, GuideME 21.1.18+ (Minecraft 1.21.1 / NeoForge builds). JEI is optional and recommended.
