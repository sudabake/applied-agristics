## 已复核的现有机制

- dry_run 默认开启，发布任务仅在关闭演练后运行。
- 上传必须等待两个依赖矩阵通过。
- 三平台共用同一构建产物，每个平台先核对内部版本、源码提交、摘要和说明。
- GitHub 上传 JAR、源码 ZIP、校验文件，另两平台仅上传 JAR。
- 普通 push 和 pull_request 不执行正式发布，上传凭据来自 GitHub Secrets。
- retry-attempts 1 在当前 mc-publish 实现中代表最多一次尝试，已经没有自动重试，保持此设置。
- 已有 GitHub 标签阻止完整重新发布。部分失败先确认远端是否收到文件，再决定重跑失败作业。
