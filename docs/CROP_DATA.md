# 种植兼容数据

设备合成成本继续暂缓。本页的 `planting` 配方只定义种子的种植行为。

优先级：本 Mod 数据配方 → 生物／神秘农业原生规则 → 可选 Botany Pots → 通用成熟作物掉落。Botany Pots 自动推导、且与现有普通作物重复的配方继续使用本 Mod 原来的周期和耕地；显式 Botany Pots 配方仍可接入。

数据包路径为 `data/<命名空间>/recipe/<名称>.json`。以下是覆盖小麦种植的示例，未作为默认配方安装：

```json
{
  "type": "appliedagristics:planting",
  "seed": {"item": "minecraft:wheat_seeds"},
  "soil": {"item": "minecraft:farmland"},
  "outputs": [{"id": "minecraft:wheat", "count": 2}],
  "display": {"Name": "minecraft:wheat", "Properties": {"age": "7"}},
  "use_loot": false,
  "ticks": 200,
  "reproduces": false
}
```

- `outputs` 第一项是目标库存对应的主产物，也用作种子转换产物。固定产物列表表示扣除重种后的净产物，支持物品组件；明确列出种子产物时不再叠加零增殖补偿。
- `soil` 可省略，此时基础机仍要求耕地；ME 使用内部虚拟土壤，不增加耕地槽。
- `ticks` 是每颗种子的一次生产周期，至少 20 tick。基础机加水后周期减半。
- `display` 是静态展示模型。`use_loot=true` 时从该成熟方块的真实掉落取产物，并保留一颗匹配种子用于重种；`outputs` 仍需声明主产物供库存目标使用。
- `reproduces` 声明掉落路线能否增殖。不能增殖时，每个实际生产周期独立补充 10% 额外种子概率。固定产物中已有种子则视为可增殖，不重复补偿。
- 配方重载会清理识别缓存。不同种子组件使用独立缓存与稳定的作物身份，目标物品保留组件。

Botany Pots 是可选前置，当前实测 21.1.44。适配读取已加载的 BasicCrop／BlockDerivedCrop 与真实土壤、周期和收获回调；不执行它的每刻生长动画。实际回调每个生产步骤最多结算 64 个周期，耗电随实际处理工作量缩减，不把少量回调结果乘大。复杂自定义 Crop 类型或无法判断增殖能力的特殊掉落可使用上述数据配方明确覆盖；没有对应上游配方的植物不会凭空获得配方。

原有普通作物的原生掉落批次仍保留最多 64 次采样的旧规则；神秘农业标准作物保留解析产量和小数累计。零增殖补偿使用二项分布批量抽样，不按并行种子逐颗循环。MA 自身额外种子被配置关闭时，也采用用户要求的 10% 补偿。
