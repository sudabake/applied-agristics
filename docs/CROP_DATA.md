# 种植兼容数据

本页的 `planting` 配方只定义种子的种植行为，设备合成配方单独维护。

优先级：本 Mod 数据配方 → 生物／神秘农业原生规则 → 可选 Botany Pots → 通用成熟作物掉落。Botany Pots 自动推导、且与现有普通作物重复的配方继续使用本 Mod 原来的周期和耕地；显式 Botany Pots 配方仍可接入。

数据包路径为 `data/<命名空间>/recipe/<名称>.json`。以下是覆盖小麦种植的示例，未作为默认配方安装：

```json
{
  "type": "appliedagristics:planting",
  "seed": {"item": "minecraft:wheat_seeds"},
  "soil": {"item": "minecraft:farmland"},
  "outputs": [{"id": "minecraft:wheat", "count": 2}],
  "display": {"Name": "minecraft:wheat", "Properties": {"age": "7"}},
  "use_loot": false,
  "ticks": 200,
  "reproduces": false
}
```

- `outputs` 第一项是目标库存对应的主产物。仅神秘农业注册作物及本 Mod 生物精华作物允许种子转换；普通种子不会因为主产物不同而被转换。固定产物列表表示扣除重种后的净产物，支持物品组件；明确列出种子产物时不再叠加零增殖补偿。
- `soil` 定义基础机的土壤要求，可省略并默认使用耕地。ME 阵列成型后不检查种子的光照、土壤、群系或基座条件；内部土壤数据仅用于读取产物和周期。
- `ticks` 是每颗种子的一次生产周期，至少 20 tick。基础机加水后周期减半。
- `display` 是静态展示模型。`use_loot=true` 时从该成熟方块的真实掉落取产物，并保留一颗匹配种子用于重种；`outputs` 仍需声明主产物供库存目标使用。
- `reproduces` 声明掉落路线能否增殖。不能增殖时，每个实际生产周期采用服务端 `fallbackSeedChance` 补充额外种子，默认 10%。固定产物中已有种子则视为可增殖，不重复补偿。
- 配方重载会清理识别缓存。不同种子组件使用独立缓存与稳定的作物身份，目标物品保留组件。

Botany Pots 是可选前置，当前实测 21.1.44。适配读取已加载的 BasicCrop／BlockDerivedCrop 与真实土壤、周期和收获回调；不执行它的每刻生长动画。实际回调每个生产步骤最多结算 64 个周期，耗电随实际处理工作量缩减，不把少量回调结果乘大。复杂自定义 Crop 类型或无法判断增殖能力的特殊掉落可使用上述数据配方明确覆盖；没有对应上游配方的植物不会凭空获得配方。

ME 阵列对已识别作物直接结算收获，Botany Pots 路线使用已解析的内部土壤信息读取实际掉落，不执行外部生长条件检查。基础种植机通过各自的土壤与生长条件校验后收获。

原有普通作物的原生掉落批次仍保留最多 64 次采样的旧规则；神秘农业标准作物保留解析产量和小数累计。零增殖补偿使用二项分布批量抽样，不按并行种子逐颗循环。MA 自身额外种子被配置关闭时，也采用 fallbackSeedChance 补偿，默认 10%。

## 生物种子与种子去向

- 地种继承原版作物 0～7 年龄。未成熟收获返还原物种种子；成熟收获返还种植用种子、1 份对应生物精华，并按 fallbackSeedChance 判定额外种子。每株的物种身份保留在原有方块实体中。
- ME 生物作物每轮产生 1 份对应精华，额外种子采用同一配置概率；种植用种子只被占用，不在每轮额外复制一份。
- 普通作物读取成熟作物掉落，扣除一颗匹配种子用于重种，再处理净产物。能原生增殖的作物不叠加补偿概率。
- 同阵列 ME 种子仓直接收取新种子；普通种子仓不会自动回填。没有 ME 种子仓时，新种子进入作物仓／输出仓。
- 装转换模块时，仅精华作物先补满并行，再将剩余新种子按 1:1 转为精华。普通作物保持未装模块的行为；胡萝卜／土豆只补足并行，剩余作为作物输出。
- JDTE 0.6.4.3 可选适配在通用作物解析后保存种子身份，通过普通／大型温室的原生批量采样路径提供对应精华与新增种子，避开动态 HarvestGenerator 的共享调用预算。工作量、能量、流体、增幅、容量预留及结算沿用 JDTE；种植材料保留，不重复输出原种子。显式温室配方优先。
- JDTE 批量增殖沿用原生每批最多四次采样并成组放大的规则，装精华转换升级时为一次采样。fallbackSeedChance 默认仍为 10%，长期期望保持，每批种子数量可能成组波动；地种与 ME 阵列继续各自的抽样规则。缺少批量接口时回退原有带身份的动态回调，未安装 JDTE 时不加载其类。

## 服务端配置

数值配置来自 NeoForge SERVER 类型的 appliedagristics-server.toml，由服务器决定；修改后保存并重启世界，确认日志加载的是该世界／服务器实际使用的配置。旧配置键保持可读，新键缺失时使用原有默认值。配方重载只重载配方，不代替数值配置的重启。

| 参数 | 默认值 | 单位和作用 |
|---|---:|---|
| earlyCycleTicks / wateredCycleTicks | 200 / 100 | 基础机无水／有水周期，tick |
| waterPerHarvestMb | 100 | 每次水加速收获的 mB |
| networkCycleTicks | 200 | 每颗种子每轮需要的基础工作量 |
| maximumParallel / maximumSpeedMultiplier | 256 / 256 | 四模块的并行容量／速度上限 |
| aePerCropPerTick / fullUpgradeAePerCropPerTick | 4 / 5000 | 每作物基础／满配 AE/t，非 FE/t |
| fallbackSeedChance | 0.10 | 无原生增殖时的补偿概率，范围 0～1 |
| meBioCycleTicks / meBioAePerTick | 200 / 4 | ME 生物培养器基础工作量 tick／AE/t，无耗水 |
| altarCycleTicks | 100 | ME 注魔祭坛基础时间，tick |

## 默认产能组合

条件：20 TPS、每轮一份精华、占满并行、不计转换、无断电／堵塞。生物作物可直接按下表换算精华；其他作物还需乘各自每轮净掉落。表内单位为轮/秒，近似值为长期平均，结算保留未完成工作量。

| 速度模块 | 0 并行：1颗 | 1 并行：4颗 | 2 并行：16颗 | 3 并行：64颗 | 4 并行：256颗 |
|---|---:|---:|---:|---:|---:|
| 0：×1 | 0.10 | 0.40 | 1.60 | 6.40 | 25.60 |
| 1：×2 | 0.20 | 0.80 | 3.20 | 12.80 | 51.20 |
| 2：×7.10 | 0.71 | 2.84 | 11.36 | 45.46 | 181.84 |
| 3：×36.66 | 3.67 | 14.66 | 58.66 | 234.63 | 938.51* |
| 4：×256 | 25.60 | 102.40 | 409.60* | 1638.40* | 6553.60* |

无作物仓时，标 * 的组合也被限制在最多 256 轮/秒；增加输出仓数量不会取消这一统一批次上限。复杂提供者的精确回调也可能限制为每批 64 轮。实际吞吐还取决于输出库存、管道、TPS 和当前种子占用数量，不能直接用界面一秒刷新一次判断速度是否生效。

## ME 生物流程与 JEI 信息页（2026-11-05）

- 已采样的生物棉签、营养试剂、空白生物种子各一份，在 ME 生物培养器中加工成对应物种的生物种子。基础 200 tick、4 AE/t，四张独立加速卡分别使速度和工作耗电翻倍，不耗水。
- 营养试剂使用一桶水、骨粉与下级精华合成；水桶按原版合成剩余物规则返还空桶。
- “种植产物”JEI 页只列可能产物类型，各图标数量为 1，包含种植材料本身，不表示净产量、概率或保底掉落。读取当前支持的种植来源与掉落表，重载后刷新；没有新增树苗种植实现。
- ME 种子仓可自动收容外部网络种子，过滤选择全部、原版、神秘农业或生物，默认全部且自动收容关闭。既有库存不因改变过滤而删除。推出种子关闭自动收容并暂停占用作物，外部存储拒收的部分留在仓内。
- 控制器“新种子默认启用”仅影响之后首次出现的作物身份，默认关闭；既有手动暂停和目标库存保留。
