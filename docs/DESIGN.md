# 设计记录

## 已确定的方向

- 项目名称：Applied Agristics。
- 定位：AE2 × Mystical Agriculture 附属 Mod。
- 目标：前期种植辅助、单方块祭坛、虚拟种植。
- 主线：Minecraft 1.21.1 / NeoForge / Java 21。
- 后续移植：Minecraft 1.20.1 / Forge / Java 17；先完成主线再移植。
- 前置策略：在对应平台的稳定发布序列中，以最新稳定版开发和测试，以上一稳定版作为最低支持目标；Alpha / Beta 不参与“上一稳定版”的计算。
- 原创内容许可证：LGPL-3.0-only。

依赖候选版本、上游限制及验证状态见 [DEPENDENCIES.md](DEPENDENCIES.md)。当前版本范围是开发目标，不是已经测试通过的兼容性声明。
